# 《畅游正定古城》3D 项目设计方案

## 一、项目背景与目标

依据《正定文物古迹分布示意图》，构建一个可在浏览器中运行的 3D 古城漫游应用，直观呈现正定"九楼四塔八大寺"及城内外文物古迹的空间格局与历史风貌。

核心目标：

1. **方位准确**：以长乐门（南城门）为正南方基准，所有建筑按真实相对方位落位；
2. **内容丰富**：古城内外均有大量建筑填充，还原城防、街巷、寺院、民居、河流环境；
3. **交互完备**：滚轮缩放、360° 全景环绕、点击景点自动飞行跳转、每个景点配简介；
4. **导航辅助**：提供指南针与区域导航缩略图（小地图），随时可知自身方位；
5. **零门槛运行**：既可用本地服务器访问，也可双击 `index.html` 直接打开。

## 二、技术选型

| 项目 | 选型 | 说明 |
| --- | --- | --- |
| 渲染引擎 | Three.js r160（WebGL） | 成熟的浏览器 3D 引擎，生态完善 |
| 语言 | 原生 JavaScript ES Module | 无框架依赖，结构轻量 |
| 相机控制 | OrbitControls | 原生支持旋转/缩放/平移/自动环游 |
| 构建工具 | esbuild | 一条命令打包为单文件 IIFE，解决 file:// 下 ES Module 被拦截问题 |
| 本地服务 | Node.js 内置 http（`server.cjs`） | 零依赖静态服务器 |
| UI | 原生 HTML/CSS | 古风深色描金视觉风格 |

## 三、总体架构

```
index.html              页面骨架（顶栏 / 侧栏 / 简介面板 / 指南针 / 小地图）
css/style.css           UI 样式
js/
├── data.js             景点数据（33 处古迹：坐标、类别、级别、简介）
├── builders.js         古建构件库（屋顶、殿堂、楼阁、四塔、城门、民居、树、标签）
├── world.js            世界组装（地形、河流、道路、城墙、建筑填充、实例化树木、网格合并）
└── main.js             场景/光照/渲染循环、射线拾取、相机动画、UI 联动
server.cjs              零依赖静态文件服务器
dist/app.js             esbuild 打包产物（含 Three.js，供 file:// 直接打开）
```

渲染启动流程：

```
main.js
  ├─ 场景/相机/渲染器/光照初始化
  ├─ buildWorld(scene)            world.js
  │    ├─ 地形、滹沱河、道路
  │    ├─ 城墙、城门洞、垛口、护城河
  │    ├─ 城内民居、城外村庄（确定性随机）
  │    ├─ 树木（InstancedMesh 两批）
  │    ├─ 静态网格按材质合并（mergeGeometries）
  │    └─ 景点模型构建并注册拾取
  └─ 渲染循环：相机动画 + 标记脉动 + 指南针 + 小地图重绘
```

## 四、方位与坐标体系

数据坐标采用直观的地理方位约定（`js/data.js`）：

- `x` 轴：**东为正、西为负**
- `z` 轴：**北为正、南为负**
- `y` 轴：高度
- 长乐门 `(0, -820)` 位于正南，城墙范围约 `x ∈ ±700，z ∈ ±820`

Three.js 默认相机在 -Z 方向向北看时，屏幕右方对应场景 -X，与"左西右东"相反。因此世界放置层统一做映射：

```js
// 数据东(+x) → 场景 -X；北(+z) 不变
const SX = x => -x;
scene.position = (SX(poi.x), poi.z)
```

小地图与指南针同样在"数据方位坐标"中计算，再经同一映射换算，保证：

- 滹沱河在画面远方（南）；
- 隆兴寺在城东（画面右）；
- 开元寺在城西（画面左）；
- 指南针红色 N 针始终指向真实北方。

## 五、内容设计

### 5.1 九楼

- 四城楼：长乐门（南，"三关雄镇"）、永安门（北，"拱护神京"）、迎旭门（东，"光含瀛海"）、镇远门（西，"秀挹太行"），城台开拱洞、上建重檐城楼，悬真实题额牌匾；
- 四角楼：城墙转角处二层角楼；
- 阳和楼：金末元初跨街高台楼阁，元曲摇篮，台开券洞、上建殿堂与两侧碑亭。

### 5.2 四塔（按真实形制分别建模）

| 塔 | 俗称 | 形制特征 |
| --- | --- | --- |
| 天宁寺凌霄塔 | 木塔 | 八角九层楼阁式，木栏平座，通高 41 米，四塔最高 |
| 开元寺须弥塔 | 砖塔 | 方形九层密檐，唐建，清秀挺拔，类大雁塔 |
| 临济寺澄灵塔 | 青塔 | 八角九层密檐，莲座、相轮宝珠塔刹，临济宗祖庭 |
| 广惠寺华塔 | 花塔 | 主塔+四角小塔，上部锥形花束塔身满布雕塑，海内孤例 |

### 5.3 八大寺

- **隆兴寺**（重点）：照壁、山门、天王殿、大觉六师殿遗址（残柱）、十字抱厦摩尼殿、戒坛、三层大悲阁、左右配阁、毗卢殿、回廊，完整多进中轴院落；
- 崇因寺、弘济寺（遗址）、舍利寺（遗址）、县文庙（五代大成殿）、府文庙、赵云庙、清真寺（中式殿顶+穹顶）等。

### 5.4 其他古迹

荣国府（多进多路四合院+宁荣街格局）、马家大院、蕉林书屋、王士珍旧居、城隍庙遗址、真武庙，以及城外小客龙山文化、西洋庄仰韶文化、新城铺商代、高平商代、王家坟墓地等史前/商周遗址（以碑识标识）。

### 5.5 环境填充

- 城内：数百栋民居（灰瓦坡顶、米白墙体）、棋盘街巷、中轴主街行道树；
- 城外：十个村庄簇（含少量现代楼房）、四门关厢街区、散植树木；
- 水系：城南蜿蜒滹沱河（沙岸+水面+河名标注）、环城护城河；
- 城防：砖砌城垣、四门开口、墙头垛口。

## 六、交互设计

1. **滚轮缩放**：OrbitControls，限定距离 60–4200，俯仰不穿透地面；
2. **360° 全景**：左键拖拽自由环绕；"360°环游"按钮开启自动旋转；
3. **点击飞行**：射线检测景点（建筑合并网格 + 隐形点击柱），点击后相机以缓动曲线（easeInOutCubic）在约 1.9 秒内飞临，并自动选择南偏东观景点位；
4. **景点简介**：左下角弹出古风面板，含名称、分类标签、保护级别、历史简介，可再次"飞临此景"；
5. **三种入口**：点击 3D 场景、点击左侧分类目录、点击右下小地图点位，均可跳转。

## 七、UI 设计

- **顶部栏**：菜单按钮、"畅游正定古城"标题、"九楼·四塔·八大寺"副题、全景/环游按钮；
- **左侧目录**：按城楼/角楼/楼阁/四塔/寺院/府邸/遗址/城外分类，彩色圆点区分；
- **指南针**：右上区域，红北白南双向针，N/E/S/W 刻度，随相机方位实时旋转；
- **区域导航缩略图**：右下角 Canvas 实时绘制——河流水系、城墙方框、中轴线、全部景点（重点古迹金色大点）、相机位置与朝向视锥；点击小点飞行到景点，点击空白处飞到该区域俯瞰；
- 景点处设置**金色光环（脉动）+ 发光柱**作为可点击提示，选中后光柱变红。

## 八、性能优化

1. **网格合并**：静态场景与每个景点分别按材质 `mergeGeometries` 合并，draw call 从数千降至数十量级；
2. **实例化渲染**：全部树木（约 1400 棵）仅用 2 个 InstancedMesh（树干/树冠），树冠使用实例色；
3. **材质与几何体复用**：屋顶按颜色缓存材质、常用几何体全局共享；
4. **确定性随机**：`mulberry32` 种子随机，建筑布局每次一致，无需存档；
5. 像素比上限 2、阴影 2048、远景雾裁剪，兼顾画质与流畅度。

## 九、运行与构建

```bash

npm run dev            # 启动 http://127.0.0.1:5173
npm run build          # 打包 dist/app.js（双击 index.html 直接运行）
双击 启动.bat           # Windows 一键打包+起服务+开浏览器
```
